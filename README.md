# 🩺 Doctor Booking App (Flutter)

A production-style **Doctor Booking Mobile Application** built with **Flutter & Dart**, implementing **Clean Architecture** and **Bloc/Cubit** for scalable state management.

The app supports **Patient & Doctor roles**, real-time appointment booking, notifications, and secure backend integration using **Firebase** and **Supabase**.

---

## 🚀 Features

### 👤 Patient
- Sign up / Login using Firebase Authentication  
- Browse available doctors  
- Book appointments (day & time)  
- Receive booking notifications  
- View appointment history  

### 🩺 Doctor
- Doctor dashboard  
- Accept or reject appointments  
- Manage availability  
- Complete doctor profile  
- Upload profile image (Supabase Storage)

## 🧱 Architecture

The project follows **Clean Architecture**:

- **Presentation Layer** – UI + Cubits  
- **Domain Layer** – Entities + Use Cases  
- **Data Layer** – Repositories + Firebase Services  

This structure ensures scalability, testability, and maintainability.
